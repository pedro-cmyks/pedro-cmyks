### Projects

* **[Atlas](https://github.com/pedro-cmyks/Observatory-Global)** · [live](https://observatory-global.vercel.app): narrative intelligence platform. Reads 150K+ news signals a day in 31 languages, groups them into stories and measures who covers them, where and with what tone. Every LLM claim is tied to a verbatim source quote.
* **[Calipso](https://github.com/pedro-cmyks/calipso)**: AI orchestration layer that routes tasks between local models and external APIs.
* **Operations CRM**: CRM for a trading operations team. Replaced a manual Excel close with an auditable daily process, plus a Windows agent that collects client data automatically. Freed up about 50% more capacity for the team.
